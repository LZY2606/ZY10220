# 固结路径查验台

本地固结试验查验台：保留完整荷载路径（首次加载 → 卸载 → 再加载），按级计算固结参数，
用 Casagrande 几何法给出先期固结压力的**多个曲率点候选与范围**。服务端用 Go 标准库
渲染 HTML + SVG，持久化使用 SQLite（纯 Go 驱动 `modernc.org/sqlite`，无需 CGO）。

## 安装与运行

```bash
go mod download
go test ./... -count=1
go run ./cmd/server --listen 127.0.0.1:5560
```

浏览器打开 <http://127.0.0.1:5560>，页面标题为“固结路径查验台”。
可选参数：`--db consolidation.db`（SQLite 文件路径，默认当前目录）。

## 页面内容

同时展示三张图：

1. **时间 - 位移**：按真实读数序列绘制；灰色虚线为仪器原始读数，彩色实线为
   修正后的物理累计压缩。位移计归零处断开续接并标记，时钟回退读数孤立成段、
   不与前后拼接。
2. **孔隙比 e - log10(p)**：首次加载、卸载、再加载分三条路径绘制并着色；
   零荷载只作为初始状态点标注，**不进入对数轴**（压力必须为正）。
   主压缩（Virgin）线与每个 Casagrande 曲率点候选的角平分线几何叠加显示，
   各候选构造出的 pc 单独打点。
3. **荷载路径**：横轴是路径顺序（不是压力排序），直观验证卸载段没有被
   排序混进首次加载曲线；归零平台与时钟回退位置在对应级上做标记。

交互操作（全部为服务端持久化的人工选择层）：

- 每级可切换**根号时间（Taylor, Tv90=0.848）**或**对数时间（Casagrande, Tv50=0.197）**，
  并修改拟合窗起止时间（分钟）。
- 可对任意读数做**级次边界修正**（改派到其他荷载级）；原始级次永久保留，可一键恢复。
- Casagrande 候选表可人工选定某个曲率点；曲率点不唯一时，页面显示先期压力范围。
- “导出运行记录(JSON)”下载完整快照；选择快照文件可“导入并清空复核”。
- “清空并重放 fixture”删除全部数据后重新导入固定样本。

## 数据口径（四层分离）

1. **原始读数层** `raw_readings`：仪器读数永不更新。字段包括读数 ID、
   原始级次 `orig_step`、当前时钟、表读数、归零标记 `reset` 与备注。
   - 表读数约定：压缩方向使读数减小（千分表向负向记）。
   - `reset=true` 表示该读数时刻位移计被归零，读数为 0，后续读数从 0 重新记起。
2. **修正值层**（计算结果，不入库）：按“归零基准 − (当前表读数 − 段起点表读数)”
   还原物理累计压缩；孔隙比按 `e = e0 − (1+e0)/H0 · s`（s 单位 mm）；
   当前厚度 `H = H0 − s/10`，排水距离 `Hd = H / 排水因子`（双面排水因子为 2）。
3. **绘图几何层**（计算结果，不入库）：分段诊断、拟合直线、d0/d50/d90/d100、
   t50/t90、主压缩线、候选点曲率与角平分线交点。
4. **人工选择层**：`step_configs`（方法与拟合窗）、`overrides`（级次边界改派）、
   `chosen_curve`（选用的曲率点序号）。这些表与原始读数完全分离。

### 荷载路径规则

- 级次严格按试验序列保留：`25→50→100→200→400→800` 加载，
  `400→200→100→50` 卸载，`100→200→400→800` 再加载。
- 卸载/再加载的 e-log(p) 点独立成线，**不按压力排序**，因此不会混入首次加载曲线。
- 零荷载没有任何步骤记录；初始状态 `(p=0, e=e0)` 只用于图上标注。

### 归零与时钟回退诊断

- **位移计归零**（fixture 第 5 级 400 kPa 平台加载瞬间）：归零读数自成一段，
  物理压缩基准继承前级末值，归零后读数续接；原始读数仍为 0，可反查。
- **时钟回退**（fixture 第 3 级 100 kPa 中插入的时间戳倒退读数）：
  回退读数单独成段，不与前后健康段连线，不参与时间拟合；
  其展示压缩取回退前最后健康读数，不允许由自身表读数推算出“伪趋势”。
- 拟合自动选择读数最多的健康分段；回退段永不参与。

### 固结参数

- 根号时间法：早期 `d-√t` 线性段回归得斜率与截距 d0，
  `√t90 = 1.15·√t100`（d100 取本级末实测相对压缩），
  `cv = 0.848·Hd²/t90`（cm²/min）。
- 对数时间法：`d0 = 2·d(0.25) − d(1)`，d100 为主固结线与窗内末段
  次固结线的切线交点，`d50 = (d0+d100)/2`，`cv = 0.197·Hd²/t50`。
- 卸载回弹段斜率为负，根号法不适用时该级 cv 留空并给出诊断说明。

### Casagrande 先期固结压力

- 只在**首次加载**曲线上计算；零荷载点和卸载/再加载点不参与。
- 每个内部点都保留为曲率点候选（Menger 圆曲率与转角）；
  弱曲率点照算几何但标记“交点无效/弱曲率”，不进入范围。
- 候选点作水平切线，与主压缩线夹角的角平分线和主压缩线交点即该候选的 pc；
  交点必须位于候选点右侧。主压缩线用“最陡折点右侧全部点”回归。
- 所有有效候选的 pc 给出 **PcLow–PcHigh 范围**；自动选择局部曲率最大者，
  也可在页面人工选定。固定 fixture 的自动 pc≈124 kPa，有效候选范围 124–147 kPa。

## 固定 fixture 与重放复核

固定样本由 `internal/fixture` 以确定性公式生成（不含随机源）：

- 试样 H0=2.00 cm，e0=2.80，面积 30 cm²，双面排水；14 个荷载级、169 条读数。
- 第 3 级（100 kPa）注入 1 条时钟回退读数；第 5 级（400 kPa）平台加载瞬间
  位移计归零。
- 首次访问页面时若数据库为空会自动导入；也可通过页面按钮或 `POST /api/reset`
  清空后重新导入。

导出 JSON（`GET /api/export`）包含运行头、级次表、**全部原始读数（含原始 ID）**、
默认/人工拟合配置、边界改派和选定曲率点。`POST /api/import` 先清空再导入，
读数主键保留——因此清空数据库重放后仍可用同一读数 ID 反查。

## 自动化测试

```bash
go test ./... -count=1
```

覆盖：fixture 确定性与阶段/异常计数、荷载路径不被排序、归零续接与可反查、
时钟回退分段且不参与拟合、两种拟合方法的 cv、Casagrande 多候选与人工选择、
级次改派、SQLite 导入/导出/清空重放、HTTP 页面与全部操作接口。

## 目录结构

```
cmd/server            服务入口
internal/domain       领域模型（运行、级次、读数、人工选择快照）
internal/fixture      固定确定性样本
internal/consolidation 分段诊断、修正值、时间拟合、e-log(p)、Casagrande
internal/store        SQLite schema 与导入/导出/人工选择持久化
internal/svg          三张 SVG 图
internal/httpapi      页面模板与 HTTP 接口
```
